T265 WebUSB Boot Lab

Checking WebUSB…
Goal: reproduce the first stage of librealsense's T265 startup in the browser. The boot device is 03E7:2150. librealsense opens USB interface 0 and sends the complete T265 VPU boot image to its first Bulk OUT endpoint. A successful boot should disconnect the Movidius device and re-enumerate the T265 runtime device, normally as 8087:0B37 (with 8087:0AF3 also recognized by librealsense rules).

Experimental: the repository does not bundle Intel firmware. The official-fetch probe below only tests whether Chrome can directly retrieve the known T265 0.2.0.951 image and verifies its size/SHA-256; the existing manual file path remains unchanged.
